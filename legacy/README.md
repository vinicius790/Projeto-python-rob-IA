# Código legado preservado

`legacy/original/` contém o conteúdo do ZIP recebido antes da evolução.

Ele existe para rastreabilidade, comparação e estudo. Não faz parte do caminho de execução da aplicação 2.0 e não recebe as mesmas garantias de teste/segurança.

Não use as integrações financeiras, configurações ou workflows antigos como exemplo de produção.
